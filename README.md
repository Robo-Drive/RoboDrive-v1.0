# RoboDrive-v1.0

## Regras de Colaboração

### 1. Revisão de Código
- Todo código desenvolvido deverá ser revisado pelo **DEV SENIOR** antes de ser integrado ao projeto.
- Nenhum código deve ser enviado diretamente para a branch principal sem revisão.
- Sugestões de melhoria devem ser consideradas antes do merge.

### 2. Organização do Código
- O código deve ser escrito de forma **clara e organizada**.
- Priorize código legível em vez de soluções complexas.
- Use nomes de variáveis e funções descritivos.
- Evite duplicação de código.

### 3. Comentários
- Evite comentários desnecessários.
- O código deve ser autoexplicativo sempre que possível.
- Utilize comentários apenas quando necessário para explicar:
  - Lógicas complexas
  - Algoritmos específicos
  - Regras de negócio importantes

### 4. Padronização
- Siga o padrão de código definido pelo projeto.
- Mantenha a identação consistente.
- Use sempre o mesmo estilo de escrita.
- Evite misturar padrões diferentes.

### 5. Estrutura do Projeto
- Respeite a organização de pastas existente.
- Não crie novas pastas sem necessidade.
- Arquivos devem ser colocados em suas pastas corretas.
